# Eduard.dev - Portfolio Website

Сучасний портфоліо сайт розроблений на **Next.js** та **React** з красивим дизайном у стилі стартапів.



## 📁 Структура проекту

```
MY SITE/
├── app/                           # Next.js app directory
│   ├── layout.tsx                 # Root layout
│   ├── page.tsx                   # Головна сторінка
│   └── globals.css                # Глобальні стилі
├── components/
│   ├── ui/                        # UI компоненти
│   │   ├── button.tsx             # Button компонент
│   │   └── card.tsx               # Card компонент
│   ├── sections/                  # Секції сторінки
│   │   ├── Header.tsx
│   │   ├── Hero.tsx
│   │   ├── About.tsx
│   │   ├── Skills.tsx
│   │   ├── Projects.tsx
│   │   ├── Contact.tsx
│   │   └── Footer.tsx
│   └── BackgroundGlow.tsx         # Фоновий ефект
├── package.json                   # Залежності проекту
├── tailwind.config.js             # Tailwind CSS конфіг
├── postcss.config.js              # PostCSS конфіг
├── tsconfig.json                  # TypeScript конфіг
├── next.config.js                 # Next.js конфіг
└── .gitignore
```

## 🛠️ Технологія

- **Next.js 14** - React фреймворк
- **TypeScript** - Типізація
- **Tailwind CSS** - Стилізація
- **Framer Motion** - Анімації
- **React** - UI бібліотека
